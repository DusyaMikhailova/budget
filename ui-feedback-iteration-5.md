# Итерация 5: интерактивные столбцы и выбор года

Этот файл уточняет годовую динамику в разделе «Аналитика». Он заменяет требование постоянно показывать суммы над всеми столбцами из итерации 4.

## Сумма по столбцу годовой динамики

- Не показывать суммы постоянно над всеми столбцами.
- При нажатии на столбец показывать одну компактную подсказку строго по центру над выбранным столбцом.
- Подсказка содержит сумму в целых рублях в российском формате: например, `1 000 ₽`.
- После выбора другого столбца подсказка переносится на него; повторное нажатие по выбранному столбцу или нажатие вне графика скрывает подсказку.
- На устройствах с курсором допустимо также показывать эту же подсказку при наведении, но основной сценарий — касание на телефоне.
- Для месяца без расходов столбец не интерактивен и подсказка `0 ₽` не показывается.
- Подсказка не должна выходить за границы карточки, пересекаться с месяцами или смещаться относительно центра столбца. При очень высокой сумме она располагается внутри верхней безопасной области графика.
- У выбранного столбца есть дополнительный неброский признак состояния: например, более насыщенный цвет или контур. Одного изменения цвета недостаточно — состояние должно быть доступно скринридеру через кнопку с понятным `aria-label`.

## Выбор года в аналитике

- Помимо выбора месяца добавить отдельный компактный контрол выбора года в разделе «Аналитика».
- Контрол показывает выбранный год, например `2026`, и открывает список только тех лет, в которых есть расходы, плюс текущий год.
- После выбора года годовая динамика пересчитывается по всем 12 календарным месяцам выбранного года.
- Месяцы без расходов остаются на графике с нулевой высотой, но без числовой подсказки до тех пор, пока в них нет трат.
- Выбор года не меняет выбранный месяц для верхней месячной аналитики: это два независимых контрола в одном разделе.

## Проверка на телефоне

1. Нажать на несколько заполненных столбцов: каждый раз видна одна сумма ровно над выбранным столбцом.
2. Нажать на пустой месяц: ничего не появляется.
3. Сменить год: график показывает 12 месяцев выбранного года, включая пустые.
4. Сменить год, затем месяц: выборы не сбрасывают друг друга.
