# Спецификация: личный трекер расходов

## 1. Назначение и границы версии

Личное мобильное PWA для одного пользователя, предназначенное только для учёта расходов в российских рублях. Приложение работает локально на телефоне, без регистрации, аккаунта, сервера, синхронизации и обязательного подключения к интернету.

Первая версия должна позволять быстро вносить расход и анализировать траты по месяцам, категориям и признаку обязательности.

Детали визуального дизайна определяются отдельным документом и не являются частью этой спецификации.

## 2. Платформа и хранение

- Мобильный web-first интерфейс на русском языке.
- PWA, доступное для установки на главный экран телефона.
- После первоначальной загрузки приложение работает офлайн: интерфейс и статические ресурсы доступны без сети.
- Все данные хранятся только на устройстве, предпочтительно в IndexedDB.
- При очистке данных браузера/приложения или смене телефона данные могут быть потеряны. Резервное копирование, импорт, экспорт и синхронизация не входят в первую версию.
- Защита PIN-кодом, биометрией и уведомления не требуются.
- Формат дат: `дд.мм.гггг`; первый день недели — понедельник.

## 3. Модель данных

### Категория

```ts
type Category = {
  id: string;
  name: string;
  icon: string;
  isDefault: boolean;
  createdAt: string;
};
```

### Расход

```ts
type Expense = {
  id: string;
  amountRubles: number; // положительное целое число
  categoryId: string;
  date: string; // YYYY-MM-DD
  isCritical: boolean;
  createdAt: string;
  updatedAt: string;
};
```

Сумма вводится и отображается только в целых рублях. Копейки не поддерживаются. Для отображения применяется российское форматирование, например `1 250 ₽`.

## 4. Категории

При первом запуске создаются стандартные категории с тематическими встроенными иконками:

- Супермаркеты
- Транспорт
- Жильё
- Здоровье
- Развлечения
- Одежда
- Путешествия
- Другое

Пользователь может создать пользовательскую категорию. При создании он указывает название и выбирает иконку из встроенного набора. Загрузка собственных изображений не нужна.

Правила категорий:

- название обязательно и уникально без учёта регистра;
- стандартные категории нельзя переименовывать или удалять;
- пользовательскую категорию можно переименовать;
- при переименовании новое название показывается у всех существующих расходов этой категории;
- пользовательские категории не удаляются в первой версии.

## 5. Операции расхода

В приложении существуют только расходы. Доходы, переводы, долги и накопления не учитываются.

Для добавления расхода обязательны:

- сумма в целых рублях, больше нуля;
- категория;
- дата;
- признак «Критичный расход».

«Критичный» означает обязательную трату, от которой пользователь не может отказаться. Значение по умолчанию — некритичный расход.

При открытии формы дата автоматически устанавливается в текущую дату устройства. Пользователь может выбрать сегодня или любую прошедшую дату. Будущие даты запрещены.

Разрешено создавать несколько расходов с одинаковыми суммой, категорией и датой.

У расхода нет названия, комментария, прикреплённого чека или фотографии.

Пользователь может редактировать или удалить любой расход. Перед удалением обязательно запрашивается подтверждение. После сохранения нового либо отредактированного расхода пользователь возвращается в историю операций. Все показатели аналитики должны пересчитываться сразу.

## 6. Экраны и функции

### 6.1. Приветственное обучение

При первом запуске показывается короткое приветственное обучение. Оно объясняет:

- что приложение помогает учитывать личные расходы;
- как добавить расход;
- что дата может быть выбрана задним числом;
- где смотреть месячную аналитику.

После завершения обучения открывается главный экран. Обучение больше автоматически не показывается.

### 6.2. Главный экран

Главный экран всегда отображает текущий календарный месяц.

На нём должны быть:

- общая сумма расходов за текущий месяц;
- график распределения текущих расходов по категориям;
- три категории с наибольшей суммой расходов за месяц;
- сумма критичных расходов;
- доля критичных расходов в процентах от общей суммы;
- действие для добавления расхода;
- переходы в историю, архив, аналитику и управление категориями.

При отсутствии расходов отображается пустое состояние с возможностью добавить первый расход.

### 6.3. Добавление и редактирование расхода

Форма содержит поле суммы, выбор категории, выбор даты, переключатель критичности, сохранение и отмену. Форма редактирования заполнена значениями выбранного расхода.

Валидация не позволяет сохранить форму без суммы, категории или корректной даты, с нулевой/отрицательной суммой, дробной суммой либо будущей датой.

### 6.4. История операций

История показывает ровно 20 последних расходов в обратном хронологическом порядке. Поиск, фильтры, группировка по дням и сводный итог за день не требуются.

Для каждой операции отображаются дата, категория с иконкой, сумма и пометка критичности, если она установлена. Операцию можно открыть для редактирования или удаления.

### 6.5. Архив

Архив содержит все расходы, включая старые. Он также отображается в обратном хронологическом порядке.

Требования:

- навигация по календарным месяцам;
- возможность перейти к любому месяцу, в котором есть операции;
- постепенная подгрузка более старых расходов действием «Показать ещё»;
- редактирование и удаление операций, включая старые;
- без полнотекстового поиска и фильтров.

### 6.6. Аналитика

Пользователь может выбрать любой прошедший месяц и увидеть:

- общую сумму расходов за месяц;
- распределение по категориям;
- сумму и процент критичных расходов;
- сумму и процент некритичных расходов;
- разницу с предыдущим календарным месяцем в рублях;
- процентное изменение относительно предыдущего месяца, если в предыдущем месяце были расходы.

Также доступна годовая динамика: пользователь выбирает год, а приложение показывает расходы за каждый из 12 календарных месяцев. Месяцы без расходов должны отображаться с нулевым значением. Для года с текущим месяцем будущие месяцы также отображаются как нулевые.

Если данных за сравниваемый предыдущий месяц нет, приложение не показывает ошибку и не вычисляет процентное изменение относительно нуля.

### 6.7. Управление категориями

Пользователь видит стандартные и собственные категории. Для собственной категории доступны создание и переименование, для новой — выбор встроенной иконки. Системные категории доступны только для использования.

## 7. Правила расчётов

- Месяц расхода определяется по его дате, а не по дате добавления.
- Месяц — календарный период с 1-го по последнее число месяца.
- Общая сумма месяца — сумма всех расходов с датами этого месяца.
- Топ-3 категории сортируются по убыванию суммы расходов в текущем месяце.
- Доля критичных расходов: `критичные расходы / все расходы × 100`.
- Абсолютная динамика: `расходы текущего месяца − расходы предыдущего месяца`.
- Процентная динамика: `(текущий месяц − предыдущий месяц) / предыдущий месяц × 100`; показатель не рассчитывается при нулевой сумме предыдущего месяца.

## 8. Исключено из первой версии

- Доходы, переводы, счета, долги, накопления.
- Лимиты и бюджеты.
- Комментарии, название покупки, фото и чеки.
- Поиск и фильтры в истории/архиве.
- Копирование или повтор расходов.
- Дробные суммы и другие валюты.
- Удаление пользовательских категорий.
- Экспорт, импорт, резервные копии, синхронизация и несколько устройств.
- Регистрация, авторизация, PIN-код, биометрия.
- Напоминания и уведомления.

## 9. Критерии готовности

1. После первого запуска пользователь видит обучение, а затем главный экран со стандартными категориями.
2. Приложение устанавливается на телефон и после первой загрузки открывается без интернета.
3. Пользователь добавляет расход за сегодня или прошлую дату; будущую дату и дробную/некорректную сумму сохранить нельзя.
4. Пользователь создаёт и переименовывает собственную категорию с иконкой; системные категории изменить нельзя.
5. Пользователь редактирует или удаляет любой расход, в том числе из архива; удаление требует подтверждения.
6. История показывает 20 последних операций, а архив позволяет перейти к месяцу и загрузить старые операции.
7. Главный экран корректно отображает текущий месяц, топ-3 категорий и долю критичных расходов.
8. Аналитика позволяет выбрать прошедший месяц, показывает распределение трат и сравнение с предыдущим месяцем.
9. Годовой график содержит все 12 месяцев выбранного года, включая нулевые.
